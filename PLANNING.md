# st_edward_church_netlify

**Status:** Pre-launch (v1 almost ready to go live as of July 2026)

## Purpose
Public-facing website for St. Edward the Confessor Catholic Church (Tallulah, LA) at `stedwardtallulah.church`. Built as a static site (Eleventy + Tailwind) and designed to serve parishioners and visitors with essential information, resources, and access to parish life.

## Public Site Sections (Current Plan)
- Home / Welcome (livestream, schedule, events, bulletin teaser)
- Resources Library (searchable)
- Bulletins Archive
- Sacraments & Forms
- Calendar & Events
- Parish Info
- Login (to private portal)

## Planned Additions (User Request)
- Sermons
- Sunday Morning Catechism
- Forms (expanded)
- Videos
- Mausoleum information

## Context for Agents
- This project is in a late planning / pre-launch state.
- The public site is the current focus for v1.
- The private admin portal is secondary to the public launch.

## Related Projects
- **parish_manager**: Powers the private admin portal (`app.stedwardtallulah.org`) and provides content management tools that feed the public site. The two projects are complementary.
